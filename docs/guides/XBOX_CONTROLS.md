# ควบคุมโมเดลด้วยจอย Xbox

เชื่อมต่อจอยกับ Windows ผ่าน USB หรือ Bluetooth แล้วเปิดหน้า Model ที่ `http://127.0.0.1:8000` กด **เปิดจอย Xbox** และกดปุ่มบนจอยหนึ่งครั้งเพื่อให้เบราว์เซอร์ตรวจพบ ปล่อยอนาล็อก/ปุ่มทั้งหมดก่อนเริ่มควบคุม ไม่ต้องล็อกเมาส์

| ปุ่ม | การทำงาน |
|---|---|
| อนาล็อกซ้าย | เดินหน้า/หลังและเลื่อนซ้าย/ขวา ความเร็วตามแรงที่ดัน |
| อนาล็อกขวา | หันมองใน Walk, Free view และมองจากจุดถ่าย |
| LT / RT | ลง / ขึ้น: ปรับความสูงใน Walk หรือบินขึ้นลงใน Free view |
| กดอนาล็อกซ้าย (L3) | เคลื่อนที่เร็วขึ้น 3 เท่า |
| A / B | เปลี่ยนเป็น Walk / Free view |
| LB / RB | เลือกจุดถ่ายก่อนหน้า / ถัดไป เมื่อโมเดลมีตำแหน่งกล้อง |
| X | กลับตำแหน่งของจุดถ่ายที่เลือกไว้ |
| Y | กลับโหมดมองจากจุดถ่าย |

เมื่อเปิดจอยจาก Capture หรือ Orbit ระบบจะเริ่ม Walk ให้ จากนั้นใช้ A/B เลือกโหมดได้ เปิดคำอธิบาย **ปุ่มจอย** ในหน้า Model ได้เช่นกัน

คลิกภาพเพื่อรับคำสั่งจอย เมื่อแก้ไขช่องบนแถบควบคุม สลับหน้าต่าง/แท็บ หรือถอดจอย ระบบจะหยุดรับการเคลื่อนที่ กลับมาคลิกภาพและปล่อยอนาล็อก/ปุ่มทั้งหมดก่อนใช้อีกครั้ง กด **ปิดจอย Xbox** เพื่อหยุดใช้งาน คีย์บอร์ดและเมาส์ยังใช้ร่วมกันได้

อนาล็อกมี dead zone 15% เพื่อกันกล้องไหล จอยต้องใช้ผัง `standard` ของเบราว์เซอร์ หากไม่พบจอยให้ตรวจการเชื่อมต่อใน Windows แล้วกดปุ่มบนจอยขณะที่หน้าเว็บเปิดอยู่ การเปิดผ่าน localhost หรือ HTTPS ช่วยให้เบราว์เซอร์อนุญาต API นี้

อ้างอิง: [Gamepad API / การตรวจพบอุปกรณ์](https://developer.mozilla.org/en-US/docs/Web/API/Gamepad_API/Using_the_Gamepad_API), [ผังมาตรฐาน W3C](https://w3c.github.io/gamepad/#remapping)
