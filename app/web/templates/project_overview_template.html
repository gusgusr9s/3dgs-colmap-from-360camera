ข้อจำกัดและงานที่ยังทำต่อได้

ยังไม่มี OBJ/triangle mesh, collision, ตัวเลือกชั้นอาคาร, ระบบเดินตามบันไดอัตโนมัติ, floor plan หรือการวัดเมตรจริงโดยไม่สอบเทียบ หน้าตัดจุดไม่ได้ซ่อมส่วนที่ไม่เคยถ่าย กระจก คนเคลื่อนที่ และผนังเรียบยังต้องตรวจภาพ/poses และถ่ายเพิ่มเมื่อจำเป็น

Ubuntu และ CUDA มีโค้ด/คำสั่งรองรับ แต่ต้องตรวจ driver/backend บนเครื่องปลายทาง ไม่ถือว่าการทดสอบ Windows/AMD ยืนยัน NVIDIA ทุกใบหรือ Ubuntu ทุกเครื่อง
