# แผนพัฒนา Model Room

## แนวทาง

ยึด GLB/glTF, OBJ, PLY และรูปแบบ Gaussian ที่ใช้งานทั่วไป รับไฟล์จากโปรแกรมใดก็ได้ ไม่กำหนดว่าต้อง export จากแอปหลักหรือมี manifest เฉพาะ ข้อมูลตรวจชนและจุดเริ่มเดินเป็นข้อมูลเสริม มี adapter สำหรับไฟล์เดิมแยกจากการเปิดไฟล์ทั่วไป ดูข้อจำกัดจริงใน [FORMATS.md](FORMATS.md)

## พัฒนาแล้ว

- รับ GLB/glTF 2.0, OBJ, PLY Mesh/Point Cloud แบบ ASCII/binary, Gaussian PLY, gzip SPZ v1–3 และ raw SPLAT
- นำเข้า ZIP ทั่วไปที่รวม glTF/buffer/texture หรือ OBJ/MTL/texture พร้อมหน้าตรวจรายการก่อนบันทึก
- คงตำแหน่งโมเดล ไฟล์ประกอบ และข้อมูลฉากเดิม โดยไม่ต้องมี manifest เฉพาะ
- ใช้พื้นและกำแพงตรวจชน จุดเริ่มเดิน และ player settings เมื่อไฟล์มีข้อมูลให้
- รับ navigation sidecar/extras ที่มีเอกสารเปิดเผย และรับ scene package เดิมผ่าน adapter
- แสดงกล้อง perspective ที่ฝังใน glTF ในรายการจุดนำทาง
- บันทึกมุมมอง Orbit/Walk/Free ได้กับไฟล์ทุกชนิด พร้อมตรวจการแก้ข้อมูลชนกันจากหลายหน้าต่าง
- สร้างและเก็บภาพปกเมื่อผู้ดูแลเปิดโมเดลครั้งแรก เปลี่ยนภาพปกเองได้ และแสดงจำนวนจุด/จุดยอดในคลัง
- เปลี่ยนชื่อ Project เลือกหลายรายการ ย้าย Project และลบหลายรายการ
- ค้นหา กรองชนิดไฟล์ และเรียงตามล่าสุด/ชื่อ/ขนาด
- อัปโหลดเป็นคิวพร้อมผลรายไฟล์ ข้ามไฟล์เสีย และหยุดหลังไฟล์ปัจจุบัน
- จัดเมนูพร้อมไอคอน dialog ตั้งค่า drawer มือถือ และการใช้งานด้วยคีย์บอร์ด
- ตั้งค่าเพดานเริ่มต้น 2 GB ให้ตรงกันทั้ง Python/Compose/systemd/Nginx และแสดงค่าจริงจากเซิร์ฟเวอร์
- cache ทั้งไฟล์เดี่ยวและไฟล์ประกอบใน ZIP พร้อมตรวจสิทธิ์และรุ่นก่อนนำ cache มาใช้
- ทดสอบ HTTP กับไฟล์ทั่วไปที่ไม่มีข้อมูลจากแอปหลัก และทดสอบ Chromium/GPU พร้อมจับภาพหลายขนาดหน้าจอ

## งานถัดไปที่แยกจากรอบนี้

1. เพิ่ม Draco/Meshopt/KTX2 decoder และ SPZ v4 โดยทดสอบความเข้ากันได้ของ renderer ก่อน
2. เพิ่มสิทธิ์การเข้าถึงแยกตาม Project หากต้องใช้กับหลายทีม
3. เพิ่ม collision จาก Mesh ปกติเมื่อจำเป็น โดยประเมินความเร็วและหน่วยความจำจากฉากใช้งานจริง

ยังไม่ทำ mesh reconstruction อัตโนมัติทั้งฉาก การตรวจชนปัจจุบันใช้กล่องที่ระบุไว้เท่านั้น
