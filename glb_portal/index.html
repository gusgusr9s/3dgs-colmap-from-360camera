    เลือกไฟล์แบบไหนดี?
    GLB / glTF 2.0
    ฉาก Mesh, วัสดุ, texture, animation หรือ Gaussian extension · รับไฟล์จากโปรแกรมทั่วไปได้
    OBJ / PLY
    OBJ สำหรับ Mesh, PLY สำหรับ Mesh หรือ Point Cloud ทั้ง ASCII และ binary · PLY แบบ Gaussian ใช้ binary little-endian float32
    SPZ / SPLAT
    Gaussian แบบบีบอัด SPZ v1–3 หรือ raw SPLAT
    ZIP
    รวม glTF กับ .bin/texture, OBJ กับ MTL/texture หรือหลายโมเดลพร้อมกัน ไม่ต้องมี manifest เฉพาะ · ตรวจรายการก่อนนำเข้า

    ไฟล์เดี่ยว GLB/glTF ต้องฝังไฟล์ประกอบไว้ภายใน หากแยกไฟล์ให้ส่งเป็น ZIP · GLB/glTF ที่ต้องใช้ Draco, Meshopt หรือ KTX2 decoder ยังไม่รองรับ
