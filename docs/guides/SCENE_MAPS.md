# รวมโมเดลเป็นฉาก / Map

เปิด **Scenes / Maps** จากเมนูเว็บหลัก หรือปุ่ม **รวมหลายโมเดล** ในหน้า Models
แล้วตั้งชื่อและสร้างฉาก เลือก PLY และ SPZ ที่พร้อมใช้งานได้หลายรายการก่อนกดเพิ่ม
แต่ละโมเดลย้าย หมุน ปรับสเกล ซ่อน ทำสำเนา หรือลบออกจากฉากได้
ใช้ตำแหน่งและสเกลปรับรอยต่อของห้องหรือพื้นที่ที่ถ่ายแยกกันด้วยตัวเอง
ใช้จุดตรงกันอย่างน้อยสามคู่เพื่อคำนวณตำแหน่ง มุมหมุน และสเกลให้เข้ากันได้
ผู้ใช้ต้องระบุจุดคู่เอง ระบบยังไม่ค้นหาจุดซ้อนหรือเย็บรอยต่อภาพอัตโนมัติ

## หน้าจัดฉาก

รายการโมเดลและกล่องตรวจชนอยู่ด้านซ้าย กด **เพิ่มโมเดล** เพื่อเปิดคลัง ค้นหาและเลือกหลายรายการ
แล้วกดเพิ่ม คลังจะแสดงชื่อสถานที่และชนิดไฟล์ ชื่อไฟล์เดิมดูได้เมื่อนำเมาส์ชี้ที่รายการ
เครื่องมือ **ย้าย / หมุน / สเกล** และ **ทดลองเดิน** อยู่เหนือภาพเสมอ
ตัวเลือกแกนกับ Snap อยู่ในเมนู **แกน / Snap** ส่วนกริด กล่องตรวจชน และคืนมุมกล้องอยู่ในเมนูรูปตา

แผงด้านขวามีสามแท็บ: **วัตถุ** สำหรับแก้ตำแหน่งและขนาด, **จัดแนว** สำหรับจุดคู่และระยะจริง,
และ **การเดิน** สำหรับขนาดผู้เดินกับจุดเริ่ม ปุ่มคืนค่าอยู่ในเมนู **คืนค่า** ข้างทำสำเนา
กด **ส่งออก** บนหัวหน้าเพื่อเลือก GLB, ZIP, OBJ หรือข้อมูลฉาก JSON
บนมือถือใช้แถบด้านล่างเปิดรายการ เครื่องมือ คลัง และส่งออก ปิดแผงด้วยปุ่ม × หรือ Esc

## ลากแกนและ Reset

คลิกโมเดลในภาพหรือรายการ แล้วเลือก **ย้าย W**, **หมุน E** หรือ **สเกล R**
ลากแกนสีแดง X / เขียว Y / ฟ้า Z ที่แสดงบนโมเดล การลากหนึ่งครั้งย้อนกลับด้วย Undo ครั้งเดียว
กด X/Y/Z เพื่อจำกัดแกน กดซ้ำเพื่อเปิดทุกแกน และเลือกแกนโลกหรือแกนของโมเดลได้
โมเดล splat ปรับสเกลเท่ากันทุกแกน ส่วนกล่องตรวจชนปรับขนาดแยกแกนได้
กล่องตรวจชนหมุนได้ทั้งสามแกน รวมถึงพื้นเอียง เปิด Snap เพื่อกำหนดระยะย้ายและมุมหมุนเป็นขั้นได้

ปุ่ม Reset ข้างแต่ละแกนคืนค่าของแกนนั้น ปุ่ม Reset ตำแหน่ง/มุม/สเกลคืนค่าทั้งชุด
ปุ่มลัดเมื่อไม่ได้พิมพ์ในช่องกรอก:

| ปุ่ม | การทำงาน |
|---|---|
| W / E / R | ย้าย / หมุน / สเกลสิ่งที่เลือก |
| X / Y / Z | จำกัดแกนของเครื่องมือ |
| Alt+G | Reset ตำแหน่ง |
| Alt+R | Reset มุมหมุน |
| Alt+S | Reset สเกล |
| Home | คืนมุมกล้องพรีวิว |
| Esc ระหว่างลาก | ยกเลิกการลากครั้งนั้น |
| Ctrl+Z / Ctrl+Shift+Z | Undo / Redo |

การ Reset ทำกับสิ่งที่เลือกและย้อนกลับได้ โหมด Walk ใช้ WASD สำหรับเดินตามเดิม

## บันทึกและเปิดกลับมา

ฉากเก็บใน `web_data/scenes/` ของ workspace เป็น JSON ที่อ้างอิงโมเดลในคลัง
พร้อม position/rotation/scale พื้น กำแพง มุมกล้อง และจุดเริ่มเดิน
การจัดฉากไม่เขียนทับ PLY/SPZ การบันทึกตรวจ revision เพื่อป้องกันหลายแท็บทับงานกัน
ถ้าฉากถูกแก้จากอีกแท็บ ให้ดาวน์โหลดงานปัจจุบันหรือคัดลอกค่าที่ต้องเก็บก่อนโหลดฉากใหม่

ดาวน์โหลดฉาก JSON แล้วนำเข้าจากหน้า Scenes เพื่อสร้างสำเนาได้
JSON ไม่รวมไฟล์โมเดล: ต้องมี PLY ชื่อเดิม หรือ SPZ/GLB record เดิมในคลังปลายทาง
อย่าลบหรือเปลี่ยนชื่อโมเดลที่ยังใช้ในฉาก หากต้นทางหายให้ลบรายการนั้นหรือเลือกโมเดลใหม่

## สเกลและระดับพื้น

แต่ละ reconstruction อาจมีหน่วยและทิศขึ้นต่างกัน ให้ปรับ rotation และ uniform scale
ให้ทุกพื้นที่ตรงกันก่อนวางพื้น/กำแพง เมื่อเทียบกับระยะที่ทราบจริงแล้วจึงตั้งหน่วยฉากเป็นเมตร
การเปลี่ยนป้ายหน่วยอย่างเดียวไม่ได้สอบเทียบหรือเปลี่ยนขนาดโมเดล
ปรับขนาดตัวผู้เดินและความเร็วให้สัมพันธ์กับหน่วยของฉาก

เลือกโมเดลแล้วกด **เลือกจุด A/B** คลิกสองตำแหน่งที่ทราบระยะจริง กรอกระยะเป็นเมตร
และกดสอบเทียบ ระบบปรับโมเดลทั้งหมด กล่องตรวจชน มุมกล้อง และจุดเริ่มเดินร่วมกัน
ขนาดและความเร็วของผู้เดินยังเป็นค่าระดับมนุษย์ตามเดิม การสอบเทียบย้อนกลับด้วย Undo ได้

## จัดแนวด้วยจุดคู่

เลือกโมเดลที่จะย้าย แล้วเลือกโมเดลอ้างอิงในแผงจัดแนว เลือกจุดบนแต่ละโมเดล
หรือกรอกพิกัดโลก XYZ แล้วเพิ่มคู่ ทำอย่างน้อยสามคู่ที่ไม่อยู่บนเส้นเดียวกัน
จุดแต่ละคู่ต้องเป็นบริเวณเดียวกันของสถานที่ที่ถ่ายซ้อน หากต้องการรักษาขนาดให้ปิดปรับสเกล
กดจัดแนวแล้วตรวจรอยต่อและค่า RMS ยิ่งต่ำยิ่งใกล้จุดที่ระบุ การจัดแนวทั้งครั้งเป็น Undo หนึ่งขั้น
การคลิก splat เลือกศูนย์กลาง Gaussian ที่อยู่ใกล้จุดคลิก จึงควรซูมและตรวจพิกัดก่อนเพิ่มคู่

## เพิ่มวัตถุ GLB

ใช้ช่องนำเข้า GLB เพื่อเพิ่มเฟอร์นิเจอร์หรือ mesh ลงคลังและฉาก ปรับตำแหน่ง/หมุน/สเกล
และเลือกจากภาพได้เหมือนโมเดลสถานที่ รองรับ GLB 2.0 ไม่เกิน 256 MB ที่รวม textures/buffers
ในไฟล์เดียว รุ่นนี้ไม่รองรับ Draco, Meshopt หรือ KTX2 ให้ส่งออก mesh แบบไม่บีบอัดเหล่านี้
mesh ที่นำเข้าเป็นภาพวัตถุ การเดินยังตรวจชนเฉพาะกล่องที่กำหนด ให้เพิ่มกล่องให้วัตถุที่ต้องการกั้น

## พื้นและกำแพงตรวจชน

เพิ่มพื้นหรือกำแพงแล้วแก้ตำแหน่ง ขนาด และมุมหมุน XYZ
ตำแหน่งของกล่องคือ **กึ่งกลาง** กล่อง เช่น พื้นหนา 0.2 ที่ต้องการผิวบน Y=0
ให้ตั้ง position Y=-0.1 ปิดการตรวจชนของแต่ละกล่องได้ และซ่อนภาพกล่องโดยยังคงการตรวจชนได้
กล่องใหม่ผูกกับโมเดลที่เลือกและเคลื่อน/หมุน/ย่อขยายตาม ใช้ช่อง **ผูกกับโมเดล** เพื่อเปลี่ยนเจ้าของ
หรือเลือกอิสระในฉาก การเปลี่ยนเจ้าของรักษาตำแหน่งและขนาดที่เห็นไว้ ช่องแก้ไขแสดงพิกัดโลก
ทำสำเนาโมเดลจะคัดลอกกล่องที่ผูกไว้ด้วย ลบโมเดลจะลบกล่องที่ผูกอยู่

เลือกโมเดลแล้วกด **สร้างพื้น/กำแพงจากกรอบโมเดล** เพื่อสร้างพื้นหนึ่งกล่องและกำแพงสี่ด้าน
จากขอบเขตหลังย้าย/หมุน/สเกล พื้นจะอยู่ที่ Y ต่ำสุดของกรอบ โมเดลที่มีจุดฟุ้งรอบนอก
อาจได้กรอบใหญ่กว่าห้องจริง จึงต้องตรวจตำแหน่งและปรับก่อนใช้
วิธีนี้ไม่ได้ตรวจผิวห้องจาก splats กำแพงที่สร้างจะปิดทั้งสี่ด้าน ให้ลบหรือย่อส่วนที่เป็นประตู
และกำแพงที่ขวางรอยต่อระหว่างโมเดล การสร้างทั้งหมดเป็น Undo หนึ่งครั้งและส่งออก OBJ ได้

โหมด Walk ใช้ WASD และ Shift เดินเร็ว กล้องอยู่สูงจากพื้นตามความสูงตัวผู้เดิน
ตรวจชนกับกล่องที่เปิดใช้งาน มีแรงตก การไถลตามผนัง และขึ้นขั้นเตี้ยได้
ส่วนที่ยังไม่ได้วางกล่องไม่มีพื้นผิวสำหรับตรวจชน จึงควรกำหนดจุดเริ่มเดินบนพื้นที่ที่วางไว้
รองรับกล่องเอียง ส่วนบันไดและพื้นผิวละเอียดต้องวางกล่องให้เหมาะสมหรือพัฒนา collision mesh เพิ่ม

**ดาวน์โหลดพื้น/กำแพง OBJ** สร้างผิวสามเหลี่ยมจากกล่องที่เปิดตรวจชนในฉากที่บันทึกล่าสุด
ได้พิกัดและขนาดเดียวกับฉาก ใช้นำเข้าเครื่องมือ 3D ต่อได้
ฉาก JSON และ OBJ เป็นการส่งออกคนละส่วน ไม่รวมภาพ splat เป็น mesh

## ส่งออกฉากเป็น GLB

กด **ส่งออก GLB ฉาก** เพื่อรวมโมเดลที่แสดงอยู่เป็นไฟล์เดียว ระบบบันทึกการแก้ไขก่อนส่งออก
แล้วแสดงความคืบหน้าเบื้องหลัง เมื่อเสร็จกด **ดาวน์โหลด GLB** หรือ **ดู GLB** เพื่อตรวจภาพ
PLY/SPZ ยังคงเป็น Gaussian ผ่าน `KHR_gaussian_splatting` และ GLB mesh ที่นำเข้ายังคงเป็น mesh
ตำแหน่ง มุมหมุน และสเกลของแต่ละโมเดลเก็บเป็น node transforms จึงรักษารูปแบบการจัดฉากไว้
กล่องตรวจชนอยู่ในฉากย่อยชื่อ `Collision boxes` ส่วนฉากหลักแสดงภาพโมเดล
ไฟล์ยังเก็บข้อมูลฉาก มุมกล้อง และจุดเริ่มใน extras โมเดลที่ซ่อนจะไม่รวมใน GLB

ตัวเปิด GLB ต้องรองรับ `KHR_gaussian_splatting` หากต้องการแสดงส่วน Gaussian ด้วย
การส่งออกนี้ไม่ได้แปลง splat เป็นผิวอาคารสามเหลี่ยม ไฟล์ GLB แบบไม่บีบอัดจะใหญ่กว่า SPZ มาก
และ GLB จำกัดขนาดรวมประมาณ 4 GB ฉากใหญ่ควรแบ่งส่งออกหรือใช้ ZIP ที่เก็บ SPZ แทน
GLB mesh ที่ใช้ extension ซึ่งตัวรวมยังไม่รองรับจะแจ้งข้อผิดพลาดให้ส่งออกแบบมาตรฐานก่อน
ส่วน **OBJ ตรวจชน** ส่งออกเฉพาะพื้นและกำแพงที่เปิดตรวจชน ไม่รวม Gaussian หรือวัตถุ GLB

## ZIP พร้อม Viewer สำหรับย้ายเครื่อง

กด **เตรียม ZIP** ระบบบันทึกฉากแล้วจัดไฟล์เบื้องหลัง เมื่อเสร็จกดดาวน์โหลด ZIP
ภายในรวมโมเดลจริง PLY/SPZ/GLB, transforms, กล่องตรวจชน, Viewer และ dependencies
จึงเปิดได้โดยไม่ใช้อินเทอร์เน็ตหรือเซิร์ฟเวอร์เดิม แตกไฟล์ทั้งหมดก่อนใช้งาน
Windows เปิด `START_WINDOWS.cmd` ส่วน Linux รัน `bash start_ubuntu.sh` ต้องมี Python 3.10+
หรือใช้เว็บเซิร์ฟเวอร์ HTTP/HTTPS เสิร์ฟโฟลเดอร์นี้ ไม่เปิด `index.html` ผ่าน `file://` โดยตรง
Viewer หมุนดูและเดินตรวจชนได้ ZIP เป็นฉากที่บันทึกตอนเตรียมไฟล์ ให้เตรียมใหม่หลังแก้ไข
มี `manifest.json` พร้อม SHA256 ของไฟล์ ใช้ตรวจความครบถ้วนของแพ็กเกจได้

## Mesh อัตโนมัติจาก PLY / SPZ

SPZ เป็นข้อมูล Gaussian splats แบบบีบอัด มีตำแหน่ง สี ขนาด ทิศทาง ความทึบ และ SH
ไม่มีรายการผิวสามเหลี่ยม การถอด SPZ กลับเป็น Gaussian PLY จึงยังไม่สร้างพื้นผิว
อ้างอิง [รูปแบบ SPZ](https://github.com/nianticlabs/spz)

มีงานสร้าง mesh จาก Gaussian เช่น [SuGaR](https://anttwo.github.io/sugar/)
ซึ่งเป็น pipeline สร้าง/ปรับพื้นผิวเพิ่ม ต้องตรวจความเข้ากันของข้อมูลและทรัพยากรก่อนผูกกับแอป
เว็บรุ่นนี้ใช้ PLY/SPZ เป็นภาพสถานที่ และกล่องเป็น mesh ตรวจชนที่ผู้ใช้กำหนด
การสร้าง mesh ทั้งฉากอัตโนมัติยังไม่ได้เพิ่มใน pipeline

หรือใช้ `--keep-open` เพื่อเปิดหน้าต่างที่ทดสอบเสร็จแล้วค้างไว้สำหรับลองใช้งานต่อ
รัน `scripts/test_scene_layout.py --fixture <fixture.json>` ด้วย Python environment ของ Playwright
เพื่อตรวจเมนู แท็บ คีย์บอร์ด การเพิ่ม/ซ่อนโมเดล และหน้าจอ 390–1600 px พร้อมบันทึกภาพ
ใน `tools/browser-qa/scene-ui-review/`
เพิ่ม `--full-workflow` เพื่อทดสอบผูกกล่อง จัดแนวจุดคู่ สอบเทียบ Snap นำเข้า GLB
ส่งออก GLB ผสม Gaussian/mesh และตรวจภาพด้วย Three.js รวมถึงแตก ZIP เปิด Viewer
ผ่านเว็บเซิร์ฟเวอร์อีกตัวที่บล็อกการเรียกเซิร์ฟเวอร์ต้นทาง

เทสต์ครอบคลุมการเก็บหลายโมเดลพร้อม transforms, revision conflict, concurrent saves,
HTTP create/save/read/export/delete และ collision ของพื้น กำแพงหมุน กำแพงบาง มุมห้อง และขั้นเตี้ย
เทสต์ JavaScript ของ editor จำลอง DOM และ renderer จึงไม่ใช่ผลวัด GPU หรือการรับรอง FPS
