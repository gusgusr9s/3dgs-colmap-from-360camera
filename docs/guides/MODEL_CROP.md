# ตัดขอบห้องหลังสร้างโมเดล

เปิด **Model → ตัดขอบห้อง** หรือ **Models → ⋯ → ตัดขอบห้อง**.
หน้า Record บีบอัดและหน้าส่งออก GLB มีทางเข้าด้วยเมื่อยังมี PLY ต้นทางที่ใช้ได้.
การตัดทำกับ Model ที่สร้างเสร็จแล้ว ไม่ต้องสร้าง Views หรือเทรนใหม่.
บันทึกเป็น PLY รุ่นใหม่โดยเก็บต้นฉบับไว้ แล้วเตรียม SPZ ของรุ่นใหม่ให้อัตโนมัติ.

1. กด **มุมบน** แล้วปรับซ้าย–ขวา / หน้า–หลังให้ครอบพื้นที่ห้องที่ต้องการ.
2. ถ้ากรอบไม่ตรงผนัง ใช้ **หมุนกรอบตามห้อง**. กด **ด้านหน้า** เพื่อปรับพื้น–เพดาน.
3. เปิด **เก็บเฉพาะก้อนที่อยู่ในกรอบทั้งก้อน** เพื่อเอา Gaussian ก้อนยาวที่ยื่นออกนอกห้องออก.
   ถ้าผนังหรือพื้นถูกตัดมากไป ให้ขยายกรอบหรือปิดตัวเลือกนี้.
4. กด **เทียบต้นฉบับ**, **ดูส่วนที่จะลบ**, หรือ **มุมถ่าย** เพื่อตรวจขอบและรายละเอียด.
   มีจำนวนจุดที่จะเก็บ/ตัดออก พร้อมย้อนกลับและทำซ้ำ. ร่างการปรับเก็บในเบราว์เซอร์เครื่องนั้น.
5. กด **บันทึกเป็นรุ่นใหม่**. เมื่อเสร็จเปิดรุ่นหลังตัดหรือดาวน์โหลด PLY ได้ทันที.
   เมื่อ SPZ พร้อม กด **SPZ / ส่งออก GLB** แล้วเตรียม GLB ของรุ่นหลังตัดตาม
   [คู่มือ Three.js](GLB_EXPORT.md).

ถ้าต้องการผลหลังตัด ให้ดาวน์โหลดไฟล์จากรุ่นใหม่นี้; SPZ/GLB รุ่นเก่ายังคงข้อมูลเดิม.

## ลบส่วนฟุ้งเฉพาะจุดด้วยแปรง / วงเลือก

1. กด **หมุนดู** เพื่อหามุมที่เห็นส่วนเกินชัด ซูมเข้าใกล้ก่อนเลือก.
2. เลือก **แปรงลบ** แล้วลากระบาย หรือ **ลากวงเลือก** ล้อมบริเวณที่ต้องการ.
   ปรับขนาดแปรงใน Inspector ได้ จุดที่เลือกเป็นสีแดงและยังไม่ถูกลบ.
3. ค่าเริ่มต้น **เลือกชั้นด้านหน้า** ประมาณจากศูนย์กลางจุดในช่องภาพ 4 พิกเซล.
   ไม่ใช่การตรวจผนังหรือ depth ที่ถูกต้องทุกพิกเซล ตรวจสีแดงก่อนยืนยันเสมอ.
   ปิดตัวเลือกนี้เพื่อเลือกทะลุตามแนวกล้อง ซึ่งอาจรวมผนังและวัตถุด้านหลัง.
   จุดสีแดงที่ยังไม่ยืนยันยังป้องกันการเลือกชั้นลึกกว่าซ้ำด้วยแปรงจังหวะถัดไป.
4. กด **ลบจุดที่เลือก** หรือ Delete เพื่อยืนยัน; **ยกเลิกเลือก** หรือ Esc เพื่อล้างสีแดง.
5. **ย้อนกลับ / ทำซ้ำ** ใช้กับแต่ละจังหวะเลือกและการยืนยันลบ รวมถึงกรอบห้อง.
   ใช้ Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z หรือ Ctrl+Y ได้เมื่อไม่ได้พิมพ์ในช่องกรอก.
6. กด **บันทึกเป็นรุ่นใหม่** เมื่อไม่มีการเลือกค้างอยู่. รุ่นที่ลบด้วยแปรง/วงเลือกใช้ชื่อ `_edit_…`.

การเลือกใช้ศูนย์กลาง Gaussian ที่อยู่ในภาพ ไม่ตัดแบ่งก้อนที่พาดขอบแปรง.
เปลี่ยนมุมแล้วเลือกซ้ำเพื่อเก็บส่วนที่ยังเหลือ. การลบไม่ได้เติมรายละเอียดหรือซ่อมผิวที่ขาด.
ร่างกรอบ/จุดที่เลือกเก็บไว้ในเบราว์เซอร์; ประวัติ Undo/Redo เก็บสูงสุด 40 สถานะใน session ที่เปิด Editor.
ผลการเลือกแต่ละจังหวะเก็บเป็น mask ที่ไม่แก้ทับและผูกกับ SHA-256 ของ PLY ต้นทาง.
การบันทึกใช้ mask เดียวกับพรีวิวและเก็บทุก property ของจุดที่เหลือ.

ทดสอบเพิ่ม: `python -m unittest discover -s tests -p test_manual_selection.py`
และ `node tests/point_painter_ui.mjs`.

ปุ่มบันทึกจะใช้ได้เมื่อพรีวิวล่าสุดพร้อมและเหลือจุดอย่างน้อยหนึ่งจุด.
ระหว่างบันทึกจะแสดงคิว/เปอร์เซ็นต์และป้องกันส่งซ้ำ ปิดหน้าแล้วกลับมาเปิด Editor ของ
ต้นทางเดิมจากเบราว์เซอร์เดิมเพื่อดูสถานะต่อได้. กรณีการเชื่อมต่อขาด กดบันทึกอีกครั้ง
โดยไม่เปลี่ยนกรอบจะตรวจคำขอเดิม เพื่อไม่สร้างผลลัพธ์ซ้ำ.

## ทำไมซูมออกแล้วฟุ้ง

โมเดลอาจมี Gaussian ที่อยู่นอกบริเวณที่ถ่าย หรือก้อนที่มี scale ใหญ่มาก.
เมื่อมองจากจุดถ่ายอาจไม่เห็น แต่พอซูมออก ก้อนเหล่านี้ปิดทับฉากเหมือนหมอก.
การตัดตามตำแหน่งศูนย์กลางอย่างเดียวอาจเหลือก้อนที่ยื่นออกมาจากในกรอบ.
ตัวเลือกเก็บทั้งก้อนจึงตรวจขอบเขต ellipsoid ตาม scale และ rotation ของแต่ละก้อนด้วย.
เป็นการเลือกจุดตามกรอบที่ผู้ใช้กำหนด ไม่ย่อหรือแก้สี/รูปร่างของจุดที่เหลือ.

กรอบแนะนำใช้การกระจายของจุดเพื่อช่วยเริ่มเลือก ไม่ได้ตรวจพบผนังอัตโนมัติ.
ควรตรวจผนัง พื้น และเพดานก่อนบันทึก โดยเฉพาะห้องรูปทรงไม่เป็นสี่เหลี่ยม,
ฉากหลายห้อง และหลายชั้น. หน่วยยังเป็นหน่วย reconstruction ไม่ใช่เมตรจริง.
การตัดกรอบไม่เติมพื้นที่ที่ไม่เคยถ่าย และไม่แก้ผนังบิด คนซ้อน หรือความฟุ้งภายในห้อง.

## ต้องตัดตั้งแต่ Views หรือไม่

**สำหรับการเอาขอบเกินรอบห้องออก ให้ตัดหลัง Model ได้เลย.**
หากปัญหามาจากคน/ผู้ถือกล้อง, ภาพเบลอ หรือ pose ผิด ให้กลับไปตรวจ Mask,
เลือกช่วงวิดีโอ/ตำแหน่งที่ดี และสร้าง Model ใหม่. ไม่ควรตัดภาพแต่ละ View แบบเหมารวม
เพียงเพื่อซ่อนหมอกรอบนอก เพราะอาจลดภาพซ้อนทับและข้อมูลผนังที่ใช้สร้าง geometry.

## ข้อมูลที่เก็บและการทดสอบ

Editor พรีวิวด้วย Spark/WebGL2 โดยโหลด SPZ เดิมเมื่อมีรุ่นที่ตรงกับ PLY ต้นทาง.
เซิร์ฟเวอร์เลือกจุดจาก PLY เต็มแล้วส่ง mask ตามลำดับจุดให้ GPU แสดงผล.
บันทึกจะคำนวณและตรวจ hash ของชุดจุดซ้ำ จึงใช้การเลือกเดียวกับพรีวิวล่าสุด.
เลือกเก็บทั้งก้อนด้วยขอบเขต `sqrt(12)` standard deviations และ covariance ที่หมุน
เข้าสู่กรอบห้อง; โหมดศูนย์กลางใช้ตำแหน่งอย่างเดียว.

การคัดเลือกและเขียนไฟล์ใช้ CPU, อ่านต้นทางแบบ mmap และเขียนเป็นช่วงย่อย
โดยคง property, SH และชนิดตัวเลขของจุดที่เลือก. ไม่แตะ input dataset, checkpoint
หรืองาน Train. คิวบันทึกแยกจากคิว GPU และเก็บสถานะใน
`web_data/model_edits/records/<id>/`. ชื่อผลลัพธ์มี `_crop_<เวลา>_<id>.ply`
และเผยแพร่แบบไม่เขียนทับชื่อเดิม. การตัดยังใช้ RAM/CPU/disk และการพรีวิวใช้ GPU ของ browser.

Metadata เก็บต้นทาง, hash, กรอบ, จำนวนก่อน/หลัง และประวัติการตัด.
คะแนนประเมินของต้นทางเก็บแยกเป็น `parent_quality`; ไม่ถือเป็นคะแนนของรุ่นหลังตัด.
รุ่นหลังตัดไม่มี checkpoint ที่ตรงกัน จึงปิดการ fine tune จากรุ่นที่ตัดแล้ว.
หากต้องการ fine tune ให้ทำจากรุ่นต้นทางแล้วตัดขอบผลลัพธ์ใหม่.

```powershell
.\.venv-win\Scripts\python.exe -m unittest discover -s tests -p test_model_crop.py
node tests/model_crop_ui.mjs
```

ทดสอบกรอบหมุน, ellipsoid ยื่นข้ามขอบ, PLY little/big endian และ ASCII,
property/SH เดิม, การเขียนหลาย chunks, ชื่อใหม่, คำขอซ้ำ, stale source,
กรอบว่าง/ไม่ถูกต้อง, งานถูกขัดจังหวะ และ HTTP preview.
JavaScript ตรวจ undo/redo และป้องกัน response เก่าหรือพรีวิวที่ยังไม่เสร็จถูกบันทึก.

ตรวจ Chromium กับ DJI จริงวันที่ 17 ตุลาคม 2026: ตัวอย่างกรอบเก็บ 933,246
จาก 949,769 จุด (ตัด 16,523 จุด), ส่งออก GLB แล้วเปิดใน Three.js ได้ครบตามพรีวิว.
ภาพก่อน/หลังจากมุมกล้องภายนอกเดียวกันแสดงว่าหมอกรอบไกลหายไป ส่วนความฟุ้งใกล้ผนัง
ยังขึ้นกับ geometry เดิมและขอบเขตที่เลือก. ไม่ได้เทรนเพิ่มหรือประเมิน Render ภายในห้องใหม่.
